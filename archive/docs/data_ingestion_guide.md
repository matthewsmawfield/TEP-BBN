# Data Ingestion Guide

This guide provides instructions to manually download missing spectra.

## Q1009+2956_z2.504
- **Target**: Q1009+2956 at z=2.504
- **Coordinates**: RA 134.72467, DEC 29.69489
- **Instrument**: Keck/HIRES
- **Required LyA Window**: [4255.45, 4261.13] 

### KOA Download Instructions
1. Go to https://koa.ipac.caltech.edu/cgi-bin/KOA/nph-KOAlogin
2. Search for RA 134.72467, DEC 29.69489
3. Download fully reduced 1D spectra (not raw echelle).
4. Place the file in `data/raw/spectra/Q1009+2956_z2.504/`
