# TEP Prior Derivation

## Purpose
To formally derive and freeze the TEP priors used for the TEP-BBN pipeline (Gate -1). A valid prior cannot be arbitrarily unconstrained (e.g. `[0.1, 10]`); it must be fixed from independent data or fundamental TEP theory.

## Sources of Constraints
The prior must come from one of the following:

1. **Existing TEP parameter values used in C0/HC/TH**: For instance, $\beta_A = -1.0$ (conformal coupling) or $\alpha_{\log} = -7.66\times 10^{-3}$ from the laboratory density sector.
2. **GNSS/clock-network amplitudes**: TEP correlations from terrestrial multi-center clock networks (e.g., NIST FEM, $\lambda_T \approx 4200$ km).
3. **Laboratory/atomic-clock constraints**: Bounds on local variation.
4. **Explicit new derivation**: From the matter metric or screening function applicable to the typical density $\sim 10^{-2}$ cm$^{-3}$ in a DLA environment compared to the saturation scale $\rho_c \approx 20$ g/cm$^3$.
