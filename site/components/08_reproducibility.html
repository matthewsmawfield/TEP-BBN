Data Availability & Reproducibility

This work follows open-science practices. All results are fully reproducible from raw data using the documented pipeline. All numerical results, Monte Carlo simulations, and statistics are generated by deterministic Python scripts processing real observational data. The pipeline enforces rigorous reproducibility: prespecified statistical outcomes are reported without post-hoc alteration and interpreted according to the scope of each test.

Repository and Code

GitHub Repository: github.com/matthewsmawfield/TEP-BBN

The repository contains a deterministic, version-controlled cosmological analysis pipeline utilizing 27 analysis steps across 4 phases: core gates (1–8), Gate 8 calibration (step_08b, true-D injection Monte Carlo), Gate 8 wavelength- and parent-centroid-systematics sensitivity (step_08c, step_08d), disformal transport, the steady-state and ionization-equilibrium ledgers (step_11, step_12), the deuterium production and extended-channel ledgers (step_13, step_15), the species-resolved opacity three-point test (step_14), the boundary-transport consistency audit (step_16), the literature-input inversion and channel-budget audit (step_17), the boundary self-consistency solve (step_18), the eternal-surface reconciliation and self-shielded ambient-bath front mode spectrum (step_19, step_20), the canonical screening-projection audit (step_21), secondary robustness analyses, and manuscript finalization. All steps are orchestrated by scripts/run_pipeline.py with comprehensive per-step logging, SHA-256 checksum manifest generation, and a pipeline summary ledger.

All raw spectroscopic data (Keck/HIRES, VLT/UVES + Keck/HIRES, and VLT/ESPRESSO), structural likelihood matrices, and the temporal-field equation solvers are released in the Zenodo repository (DOI: 10.5281/zenodo.21841147) under CC-BY 4.0. The full codebase and execution environments are identical to the published version.

Pipeline Architecture

The analysis pipeline comprises 4 phases and 24 steps spanning spectroscopic ingestion to thermodynamic evaluation, helium synthesis, opacity boundary analysis, Gate 8 true-D injection calibration, wavelength- and parent-centroid-systematics sensitivity, disformal transport calibration, the steady-state timescale/thermalization ledger (Gate 11), the VMO ionization-equilibrium budget (Gate 12), the deuterium production ledger (Gate 13), the species-resolved opacity three-point test (Step 14), the extended deuterium channels ledger (Step 15), the boundary-transport consistency audit (Step 16), the literature-input inversion and channel-budget audit (Step 17), the boundary self-consistency solve (Step 18), secondary robustness checks, and manuscript number finalization. Each step is a standalone Python script in scripts/steps/ that produces serialized JSON outputs and detailed logs with SHA-256 checksum verification.

# 1. Clone repository
git clone https://github.com/matthewsmawfield/TEP-BBN.git
cd TEP-BBN

# 2. Install dependencies
pip install -r requirements-lock.txt

# 3. Run full pipeline (default: Q1009+2956 sightline, 1000 MC sims)
python scripts/run_pipeline.py

# 3b. Quick mode (50 MC sims, for faster testing)
python scripts/run_pipeline.py --quick

# 3c. Run a specific sightline
python scripts/run_pipeline.py --sightline PKS1937-101

# 3d. Run all sightlines with ingested data
python scripts/run_pipeline.py --all-sightlines

# 3e. Skip secondary robustness analyses
python scripts/run_pipeline.py --skip-secondary

python scripts/run_pipeline.py --n-sims 500

# 4. Results will be stored in results/ and logs/

#    SHA-256 manifest: results/checksums_sha256.json

Multi-Sightline Configuration

The pipeline supports multiple D/H absorber sightlines through per-sightline JSON configuration files in configs/sightlines/. Each config specifies the data manifest path, VPFIT model file, noise model, absorber redshift, candidate parameter bounds, multi-start initial points, and Monte Carlo settings. Three sightlines are currently supported with ingested data: Q1009+2956 (Keck/HIRES, $z=2.5042$), PKS 1937$-$101 (ESPRESSO, $z=3.572$), and J1332$+$0052 (UVES+HIRES, $z=3.421$). Sightlines without ingested data (PKS 1937$-$1009, HS 0105+1619) are automatically skipped with a diagnostic message.

Current statistical implementation

The fixed data-quality mask is shared by all hypotheses and simulations. All finite residuals contribute to the Student-$t$ likelihood; numerical forward-model or continuum failures are rejected. Continuum order is 10 for Lyman-series blocks and 5 for metal-line blocks. The per-sightline noise models, candidate bounds, multistart searches and parent-selection rules are recorded with the fitted ledgers. Both canonical-parent and parent-maximized likelihood comparisons are calibrated with $N=1000$ genuine true-D injections per sightline.

Gate 8 retains every simulation vector and its seed. Marginal consistency tests center on the empirical null means. The joint metric regularizes a dimensionless correlation matrix and uses leave-one-out null scores. Input and simulation-file hashes permit provenance checks. Gaussian systematic sensitivity calculations are distinguished from empirical injection probabilities and their finite-sampling limits. The final method does not combine these correlated diagnostics as independent evidence.

Ionization balance. The opacity calculations use the stable positive root of $x_e^2=q(1-x_e)$. At the declared baryon density, photoionization equilibrium is $\Gamma(1-x_e)=\alpha_B n_b x_e^2$. The step-16 LTE-equivalent rates therefore agree at fixed temperature across its density ladder; these are conditional equilibrium requirements, not a measured radiation field.

Likelihood and tail evaluation. All finite data residuals contribute to the likelihood. Numerical failures are rejected. Gaussian sensitivity tails use the survival function; Monte-Carlo outputs include exceedance counts, sampling resolution and one-sided 95% binomial upper bounds.
